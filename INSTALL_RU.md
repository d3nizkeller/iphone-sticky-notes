# Установка iPhone Sticky Notes для Windhawk — инструкция для новичков

Эта инструкция сделана для пользователей, которые раньше не работали с GitHub, Windhawk и модами.

## Что получится после установки

После установки на рабочем столе Windows появится маленькая синяя кнопка **+**. Нажмите её, чтобы создать стикер. В стикере можно печатать текст, двигать его за верхнюю панель, менять цвет и закрывать ненужные заметки.

## Вариант 1 — авто-помощник, самый простой

> Полностью тихой установки пользовательского `.wh.cpp`-мода в Windhawk через официальный интерфейс командной строки нет. Поэтому Авто-помощник делает всё, что можно сделать безопасно автоматически: ставит/открывает Windhawk, копирует код мода в буфер обмена и показывает, что нажать дальше.

1. Откройте страницу репозитория на GitHub.
2. Нажмите зелёную кнопку **Code**.
3. Нажмите **Download ZIP**.
4. Распакуйте архив, например на рабочий стол.
5. Откройте распакованную папку.
6. Дважды нажмите файл `install-windhawk-sticky-notes.bat`.
7. Если Windows спросит разрешение PowerShell, разрешите запуск.
8. Если Windhawk не установлен, скрипт попробует установить его через `winget`.
9. Скрипт скопирует код мода в буфер обмена и откроет Windhawk.
10. В Windhawk откройте **Mods**.
11. Нажмите **Create a new mod** / **Создать новый мод**.
12. Удалите пример кода в редакторе.
13. Нажмите **Ctrl+V** — код уже скопирован авто-помощником.
14. Нажмите **Compile Mod**.
15. Нажмите **Exit Editing Mode**.
16. Включите мод переключателем.
17. Если кнопка **+** не появилась, перезапустите Explorer или перезайдите в Windows.

Файлы авто-помощника:

- `install-windhawk-sticky-notes.bat` — файл, по которому нужно дважды кликнуть.
- `scripts/install-windhawk-sticky-notes.ps1` — PowerShell-скрипт, который выполняет автоматические шаги.

## Вариант 2 — установка через GitHub Raw-ссылку

1. Загрузите этот проект в свой GitHub-репозиторий.
2. Откройте файл `mods/iphone-sticky-notes.wh.cpp` на GitHub.
3. Нажмите кнопку **Raw**.
4. Скопируйте ссылку из адресной строки браузера.
5. Откройте Windhawk.
6. Если в вашей версии Windhawk есть **Install from URL**, вставьте raw-ссылку туда.
7. Если пункта **Install from URL** нет, используйте ручную установку ниже.
8. Скомпилируйте и включите мод для `explorer.exe`.

## Вариант 3 — ручная установка в Windhawk

1. Откройте Windhawk.
2. Перейдите в **Mods**.
3. Нажмите **Create a new mod** / **Создать новый мод**.
4. Откройте файл `mods/iphone-sticky-notes.wh.cpp` в этом репозитории.
5. Скопируйте весь код из файла.
6. Вернитесь в Windhawk.
7. Удалите пример кода в редакторе.
8. Вставьте код сочетанием **Ctrl+V**.
9. Нажмите **Compile Mod**.
10. Если компиляция успешна, нажмите **Exit Editing Mode**.
11. Включите мод переключателем.
12. Если заметки не появились сразу, перезапустите Explorer или выйдите и снова войдите в Windows.

## Как загрузить проект на GitHub через командную строку

В этой рабочей среде GitHub remote не настроен, поэтому автоматический `git push` отсюда выполнить нельзя. На своём компьютере сделайте так:

```bash
git remote add origin https://github.com/<ваш-логин>/iphone-sticky-notes.git
git push -u origin HEAD
```

Замените `<ваш-логин>` на ваш логин GitHub.

## Как пользоваться заметками

- Нажмите синюю кнопку **+**, чтобы создать новую заметку.
- Печатайте текст прямо внутри заметки.
- Тяните заметку за верхнюю белую панель, чтобы переместить её.
- Нажмите маленький цветной прямоугольник сверху, чтобы поменять цвет.
- Нажмите `x`, чтобы закрыть заметку.
- Данные сохраняются автоматически в `%APPDATA%\WindhawkStickyNotes\notes.ini`.

## Если GitHub пишет: `This branch has conflicts that must be resolved`

Такой конфликт чаще всего появляется, когда в pull request изменён `README.md`, а в основной ветке он тоже изменился. В этой версии подробная инструкция вынесена в отдельный файл `INSTALL_RU.md`, а README.md возвращён к исходному виду, чтобы убрать конфликт по `README.md`.

Если конфликт всё равно виден на GitHub:

1. Нажмите **Resolve conflicts** в pull request.
2. В файле `README.md` оставьте нужный финальный текст без строк `<<<<<<<`, `=======`, `>>>>>>>`.
3. Нажмите **Mark as resolved**.
4. Нажмите **Commit merge**.

Через командную строку это обычно выглядит так:

```bash
git fetch origin
git merge origin/main
# исправьте README.md, если Git попросит
git add README.md
git commit
git push
```
