# Установка iPhone Sticky Notes для Windhawk — инструкция для новичков

> Файл специально расположен в `docs/IPHONE_LIQUID_GLASS_STICKY_NOTES_RU.md`, чтобы не конфликтовать с `INSTALL_RU.md`, `docs/WINDHAWK_STICKY_NOTES_GUIDE_RU.md` и `mods/iphone-sticky-notes.wh.cpp` в pull request.

Эта инструкция сделана для пользователей, которые раньше не работали с GitHub, Windhawk и модами.

## Что получится после установки

После установки на рабочем столе Windows появится маленькая синяя кнопка **+** в стиле жидкого стекла. Нажмите её, чтобы создать современный стикер. В стикере можно печатать текст, двигать его за верхнюю панель, менять цвет и закрывать ненужные заметки.

## Вариант 1 — авто-помощник, самый простой

> Полностью тихой установки пользовательского `.wh.cpp`-мода в Windhawk через официальный интерфейс командной строки нет. Поэтому Авто-помощник делает всё, что можно сделать безопасно автоматически: ставит/открывает Windhawk, копирует код мода в буфер обмена и показывает, что нажать дальше.

1. Откройте страницу репозитория на GitHub.
2. Нажмите зелёную кнопку **Code**.
3. Нажмите **Download ZIP**.
4. Распакуйте архив, например на рабочий стол.
5. Откройте распакованную папку.
6. Дважды нажмите файл `install-windhawk-sticky-notes.bat`.
7. Если Windows спросит разрешение PowerShell, разрешите запуск.
8. Если Windhawk не установлен, скрипт попробует установить его через `winget`.
9. Скрипт скопирует код мода в буфер обмена и откроет Windhawk.
10. В Windhawk откройте **Mods**.
11. Нажмите **Create a new mod** / **Создать новый мод**.
12. Удалите пример кода в редакторе.
13. Нажмите **Ctrl+V** — код уже скопирован авто-помощником.
14. Нажмите **Compile Mod**.
15. Нажмите **Exit Editing Mode**.
16. Включите мод переключателем.
17. Если кнопка **+** не появилась, перезапустите Explorer или перезайдите в Windows.

Файлы авто-помощника:

- `install-windhawk-sticky-notes.bat` — файл, по которому нужно дважды кликнуть.
- `scripts/install-windhawk-sticky-notes.ps1` — PowerShell-скрипт, который выполняет автоматические шаги.

## Вариант 2 — установка через GitHub Raw-ссылку

1. Загрузите этот проект в свой GitHub-репозиторий.
2. Откройте файл `windhawk/iphone-liquid-glass-sticky-notes.wh.cpp` на GitHub.
3. Нажмите кнопку **Raw**.
4. Скопируйте ссылку из адресной строки браузера.
5. Откройте Windhawk.
6. Если в вашей версии Windhawk есть **Install from URL**, вставьте raw-ссылку туда.
7. Если пункта **Install from URL** нет, используйте ручную установку ниже.
8. Скомпилируйте и включите мод для `explorer.exe`.

## Вариант 3 — ручная установка в Windhawk очень подробно

Этот способ нужен, если авто-помощник не сработал или вы хотите всё сделать сами.

### Шаг 1. Подготовьте код мода

1. Откройте папку проекта `iphone-sticky-notes`.
2. Откройте папку `mods`.
3. Найдите файл `iphone-liquid-glass-sticky-notes.wh.cpp`.
4. Откройте файл в обычном Блокноте, Notepad++, VS Code или прямо на GitHub.
5. Нажмите **Ctrl+A**, чтобы выделить весь текст файла.
6. Нажмите **Ctrl+C**, чтобы скопировать весь код.
7. Важно: копировать нужно именно весь файл от первой строки `// ==WindhawkMod==` до последней строки.

### Шаг 2. Создайте новый мод в Windhawk

1. Откройте программу **Windhawk**.
2. Слева или сверху откройте раздел **Mods**.
3. Нажмите кнопку **Create a new mod**. В русской локализации это может называться **Создать новый мод**.
4. Windhawk откроет редактор с примером кода.
5. Нажмите внутри редактора мышкой.
6. Нажмите **Ctrl+A**, чтобы выделить пример кода.
7. Нажмите **Delete** или **Backspace**, чтобы удалить пример.
8. Нажмите **Ctrl+V**, чтобы вставить код `iphone-liquid-glass-sticky-notes.wh.cpp`.

### Шаг 3. Скомпилируйте мод

1. Найдите кнопку **Compile Mod** / **Compile** / **Скомпилировать**.
2. Нажмите её и подождите окончания компиляции.
3. Если Windhawk попросит скачать или установить компоненты компилятора, разрешите это.
4. Если появилась ошибка, проверьте, что вы вставили весь файл целиком, включая блок `// ==WindhawkMod==` в начале.
5. После успешной компиляции нажмите **Exit Editing Mode** / **Выйти из режима редактирования**.

### Шаг 4. Включите мод

1. Вернитесь на страницу мода.
2. Найдите переключатель включения мода.
3. Включите мод.
4. Мод рассчитан на `explorer.exe`, поэтому Windhawk должен применить его к Проводнику Windows.
5. Если Windhawk предложит перезапустить процесс или применить изменения, согласитесь.

### Шаг 5. Проверьте, что всё работает

1. На рабочем столе должна появиться маленькая синяя кнопка **+**.
2. Нажмите **+**, чтобы создать новый стикер.
3. Кликните внутри стикера и напечатайте текст.
4. Потяните стикер за верхнюю белую панель, чтобы переместить его.
5. Нажмите маленькую цветную кнопку сверху, чтобы поменять цвет.
6. Нажмите `x`, чтобы закрыть стикер.

### Если кнопка + не появилась

1. Откройте Диспетчер задач Windows.
2. Найдите **Windows Explorer** / **Проводник**.
3. Нажмите **Restart** / **Перезапустить**.
4. Если это не помогло, выйдите из Windows и войдите снова.
5. Проверьте в Windhawk, что мод включён и компиляция прошла без ошибок.

## Как загрузить проект на GitHub через командную строку

В этой рабочей среде GitHub remote не настроен, поэтому автоматический `git push` отсюда выполнить нельзя. На своём компьютере сделайте так:

```bash
git remote add origin https://github.com/<ваш-логин>/iphone-sticky-notes.git
git push -u origin HEAD
```

Замените `<ваш-логин>` на ваш логин GitHub.

## Как пользоваться заметками

- Нажмите синюю стеклянную кнопку **+**, чтобы создать новую заметку.
- Печатайте текст прямо внутри заметки.
- Тяните заметку за верхнюю светлую glass-панель, чтобы переместить её.
- Нажмите маленький цветной прямоугольник сверху, чтобы поменять цвет.
- Нажмите `x`, чтобы закрыть заметку.
- Данные сохраняются автоматически в `%APPDATA%\WindhawkStickyNotes\notes.ini`.

## Если GitHub пишет: `This branch has conflicts that must be resolved`

Такой конфликт чаще всего появляется, когда в pull request изменён `README.md`, а в основной ветке он тоже изменился. В этой версии подробная инструкция лежит в отдельном файле `docs/IPHONE_LIQUID_GLASS_STICKY_NOTES_RU.md`. Старые конфликтные пути `INSTALL_RU.md`, `docs/WINDHAWK_STICKY_NOTES_GUIDE_RU.md` и `mods/iphone-sticky-notes.wh.cpp` удалены из ветки, чтобы убрать конфликты по этим файлам.

Если конфликт всё равно виден на GitHub:

1. Нажмите **Resolve conflicts** в pull request.
2. В файле `README.md` оставьте нужный финальный текст без строк `<<<<<<<`, `=======`, `>>>>>>>`.
3. Нажмите **Mark as resolved**.
4. Нажмите **Commit merge**.

Через командную строку это обычно выглядит так:

```bash
git fetch origin
git merge origin/main
# исправьте README.md, если Git попросит
git add README.md
git commit
git push
```
